## What it does

App Store screenshots, blog headers, release notes — the same shot, over
and over, at exactly the same size. Do it with the system screenshot tool
and every frame comes out a few pixels off, so the set never looks like a
set.

Gripture pins the capture region to a size you choose and keeps it there.
Move the guide, capture again, and the dimensions are identical. Window
and scrolling capture work the same way.

What comes out lands in an editor that treats every image alike — a region
capture, a window capture, a photo you dropped in. Corner radius, border,
shadow and background operate on the image's own silhouette, so a window
keeps its native rounding and a photo stays sharp.

Full feature list and help: **[gripture.hobbyworker.me](https://gripture.hobbyworker.me)**

macOS 14.0 (Sonoma) or later · Apple Silicon and Intel universal binary

## 이게 뭐 하는 앱인가

앱 스토어 스크린샷, 블로그 헤더, 릴리스 노트 — 같은 장면을 몇 번이고 **같은
크기로** 찍어야 하는 일입니다. 시스템 캡처로 하면 매번 몇 픽셀씩 어긋나서,
모아놓으면 한 세트로 보이지 않습니다.

Gripture는 캡처 영역을 지정한 크기에 고정합니다. 가이드를 옮기고 다시 찍어도
치수는 그대로입니다. 창 캡처와 스크롤 캡처도 같은 방식입니다.

찍은 것은 **입력을 가리지 않는 에디터**로 들어갑니다. 영역 캡처든 창 캡처든
끌어다 놓은 사진이든 동일하게 다룹니다 — 모서리 둥글기·테두리·그림자·배경이
이미지 자신의 실루엣을 기준으로 동작하므로, 창은 원래의 둥근 모서리를
유지하고 사진은 각진 채로 남습니다.

자세한 기능과 도움말: **[gripture.hobbyworker.me/ko/](https://gripture.hobbyworker.me/ko/)**

## Gripture eXtra

Automatic scrolling capture has to drive another app's scroll, which the
App Sandbox does not allow. That part lives in a separate, optional helper
— **[Gripture eXtra](https://github.com/hobbyworker/Gripture-eXtra)** —
installed only if you want it. Gripture works fully without it; scrolling
capture simply falls back to scrolling by hand.

자동 스크롤 캡처는 다른 앱의 스크롤을 조작해야 해서 샌드박스 안에서는 할 수
없습니다. 그 부분만 **선택 설치 헬퍼**로 분리했습니다. 없어도 앱은 완전히
동작하며, 스크롤만 직접 하시면 됩니다.
